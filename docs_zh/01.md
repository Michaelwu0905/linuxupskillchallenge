## 简介

你现在应该已经有一台运行着最新 Ubuntu Server LTS（长期支持）版本的远程服务器了。你将独自管理它。要成为一名全面的 Linux 服务器管理员，你应该习惯与不同版本的 Linux 打交道，不过目前 Ubuntu 是个好选择。

一旦你在命令行上达到自如的水平，你会发现自己的技能不仅能迁移到所有标准的 Linux 变体，也能迁移到 Android、Apple 的 OSX、OpenBSD、Solaris 和 IBM AIX。整个课程中你都会在 Linux 上工作——但事实上所涉及的绝大部分内容都适用于任何源自 [UNIX 操作系统](https://youtu.be/tc4ROCJYbm0) 的系统——它们之间的主要差异在于图形用户界面，例如 Gnome、Unity、KDE 等等——而这些你一个都不会用到！

## 使用 SSH 客户端

远程访问过去是用简单的 *telnet* 协议完成的，但现在总是使用安全得多的 SSH（Secure SHell）协议。**如果你的服务器是本地虚拟机或 WSL，你可以在需要时直接使用服务器控制台/终端，从而跳过本节。** 我们会在 [第 3 天](03.md)从服务器端更详细地探讨 SSH，但知道如何使用 [ssh 客户端](https://www.ssh.com/academy/ssh/client)是一项基础的系统管理员技能，所以不妨现在就做。

### 在 MacOS 和 Linux 上

在 MacOS 机器上，你通常通过 **Terminal.app** 访问命令行——它位于 Applications 的 Utilities 子文件夹中。

在带菜单的 Linux 发行版上，你通常可以在 “Applications menu -> Accessories -> Terminal”、“Applications menu -> System -> Terminal” 或 “Menu -> System -> Terminal Program (Konsole)” 下找到终端——或者直接搜索你的终端应用。很多情况下 `Ctrl+Alt+T` 也能打开终端窗口。

打开一个“终端”会话后，你可以像这样使用命令行的 **ssh** 客户端：

`ssh user@<ip 地址>`

例如：

`ssh support@192.123.321.99`

如果远程服务器是用 SSH 公钥配置的（比如 AWS、Azure 和 GCP），那么你需要用 `-i` 开关指向私钥的位置作为身份证明，通常像这样：

`ssh -i ~/.ssh/id_rsa support@192.123.321.99`

可以用 `.ssh/config` 功能设置一个非常顺滑的连接流程——参见下面“扩展”部分中的 “SSH client configuration” 链接。

### 在 Windows 上

在较新的 Windows 10 版本上，同样的命令行客户端现在也可用，但必须[启用](https://learn.microsoft.com/en-us/windows/terminal/tutorials/ssh)（通过 “Settings”、“Apps”、“Apps & features”、“Manage optional features”、“Add a feature”、“OpenSSH client”）。

Windows 上有各种可用的 SSH 客户端（[PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html)、[Solar-PuTTY](https://solarwinds.sjv.io/c/1399142/1703707/17790)、[MobaXterm](https://mobaxterm.mobatek.net/)、[Termius](https://termius.com/free-ssh-client-for-windows) 等），但如果你使用的是比 10 更旧的 Windows 版本，建议安装 PuTTY。

另外，你也可以安装 [Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)，它会给你一个完整的本地命令行 Linux 环境，其中包含 SSH 客户端——_ssh_。

无论你使用哪个客户端，第一次连接服务器时，你可能会收到一条警告，说你要连接到一台新服务器——并被询问是否要[缓存主机密钥](https://www.ssh.com/blog/what-are-ssh-host-keys)。是的，你要。直接输入/点击 **Yes** 即可。

不过现在不用太担心 SSH 会话安全或服务器加固；我们会在[第 3 天](03.md)做这件事。

现在，只需登录到你的服务器，并记住：Linux 对用户名和密码都是区分大小写的。

你将在 SSH 客户端里花很多时间，所以花些时间定制它是值得的。至少试试 “black on white” 和 “green on black”——并试验不同的等宽字体（“Ubuntu Mono” 可以免费下载，而且非常好看）。

能够在远程会话和本地桌面之间剪切粘贴文本也非常方便，所以花点时间熟练掌握在你的 SSH 客户端和终端里怎么做这件事。

也许你现在可以试着从家里和办公室登录——甚至用手机！——使用诸如 [Termux](https://termux.dev/en/)、[Termius for Android](https://termius.com/free-ssh-client-for-android) 或 [Termius for iPhone](https://termius.com/free-ssh-client-for-iphone) 这样的 ssh 客户端应用。作为服务器管理员，你需要能自如地从各地登录。你也有可能使用像 [consolefish](https://www.serfish.com/console/) 和 [ShellHub](https://www.shellhub.io/) 这样的 JavaScript ssh 客户端，但这些选项意味着你要比大多数系统管理员在访问生产系统时所能接受的程度更信任第三方。

要登出，只需输入 `exit` 或关闭终端。

## 登录到你的服务器

登录之后，注意你得到的“命令提示符”以 `$` 结尾——这是普通用户的惯例，而拥有完整管理权限的 “root” 用户的提示符是 `#`（不过我们也会在第 3 天深入探讨这个区别）。

## 服务器基本信息

用 `lsb_release -a` 查看你正在使用哪个 Linux 发行版及其版本。[lsb_release](https://refspecs.linuxfoundation.org/LSB_3.0.0/LSB-PDA/LSB-PDA/lsbrelease.html) 在你的服务器上可能不可用，因为它没有被广泛采用，但你总能在系统文件 [os-release](https://www.man7.org/linux/man-pages/man5/os-release.5.html) 中找到同样的信息。你可以通过输入 `cat /etc/os-release` 来查看它的内容。

`uname -a` 也会打印[系统信息](https://www.man7.org/linux/man-pages/man1/uname.1.html)，它可以显示一些有趣的东西，比如内核版本、硬件平台等。

`uptime` 会显示[系统已经运行了多久](https://www.man7.org/linux/man-pages/man1/uptime.1.html)。它让 `cat /proc/uptime` 得到的那些[奇怪的数字](https://unix.stackexchange.com/questions/753868/proc-uptime-command-gives-weird-result)可读性好多了。

`whoami` 会打印你登录时使用的[用户名](https://www.man7.org/linux/man-pages/man1/whoami.1.html)，`who` 会显示[谁登录了](https://www.man7.org/linux/man-pages/man1/who.1.html)，而 `w` 还会显示[他们在做什么](https://www.man7.org/linux/man-pages/man1/w.1.html)。

## 硬件信息

`lshw` 可以给出一些[硬件配置的详细信息](https://manpages.ubuntu.com/manpages/trusty/en/man1/lshw.1.html)，我们还可以用一堆开关来过滤我们想看到的信息，但它并不是我们检查硬件时唯一使用的工具。常用的一些命令是：

* `lscpu` 显示 [CPU 架构](https://www.man7.org/linux/man-pages/man1/lscpu.1.html) 信息
* `lsblk` 列出[块设备](https://www.man7.org/linux/man-pages/man8/lsblk.8.html)
* `lspci` 列出所有 [PCI 设备](https://www.man7.org/linux/man-pages/man8/lspci.8.html)
* `lsusb` 列出 [USB 设备](https://www.man7.org/linux/man-pages/man8/lsusb.8.html)

## 测量内存和 CPU 使用情况

别担心！Linux [不会吃掉你的内存](https://linuxatemyram.com/)。但如果你想检查系统中[已使用的内存量](https://www.man7.org/linux/man-pages/man1/free.1.html)，就用 `free -h`。`vmstat` 也会给出一些[内存统计信息](https://www.man7.org/linux/man-pages/man8/vmstat.8.html)。

`top` 就像是 Linux 的[任务管理器](https://www.man7.org/linux/man-pages/man1/top.1.html)，它会显示进程和资源消耗情况。`htop` 是一个[交互式](https://www.man7.org/linux/man-pages/man1/htop.1.html)、更漂亮的版本。

## 测量磁盘使用情况

用 `df -h` 查看[磁盘空间](https://www.man7.org/linux/man-pages/man1/df.1.html)使用情况，但如果你想估算文件夹的[大小](https://www.man7.org/linux/man-pages/man1/du.1.html)，就用 `du -h`。

## 测量网络使用情况

使用 `ifconfig` 或它的现代替代品 `ip address`，你可以对网络接口及其 IP 地址有一个大致了解，但它不会显示带宽使用情况。

为此我们有 `netstat -i`，它提供一种更[静态的视图](https://www.man7.org/linux/man-pages/man8/netstat.8.html)，以及 `ifstat`，它提供[连续的视图](https://www.man7.org/linux/man-pages/man8/ifstat.8.html)。要中断 `ifstat`，只需用 `CTRL+C`。

但如果你想获得关于这些流量的更多信息，`sudo iftop -i enp1s0` 是一个[很不错的展示](https://manpages.ubuntu.com/manpages/xenial/man8/iftop.8.html)。*把 `enp1s0` 换成你想捕获流量信息的接口。* 要退出监控视图，输入 `q` 退出。
