## 简介

今天我们会以“五连击”收尾——快速介绍五个不同的主题。今天不要求精通——在接下来的课程中你会对它们做大量练习！

不要被这些命令看起来有多简单所误导——它们都有隐藏的深度，许多系统管理员每天都会用到其中好几个。

## 今天的任务

* 使用 Tab 补全
* 在命令历史中搜索
* 用 more 和 less 读取一个点文件
* 修改/定制你的提示符

用“资源”部分中的链接来完成这些任务：

* 熟悉用 `more` 和 `less` 查看文件，包括能在 `less` 中跳到文件顶部或底部，以及搜索某些文本

* 测试“Tab 补全”是如何工作的——这是一个帮你正确输入命令的便捷功能。它既能帮你找到命令，也能帮你找到文件名参数，所以输入 `les` 然后按 “Tab” 会补全成命令 `less`；而输入 `less /etc/serv` 再按 “Tab” 也会补全为 `less /etc/services`。试着输入 `less /etc/s` 然后按 “Tab”，再按一次，看看这个功能如何处理歧义。

* 既然你已经输入了不少命令，试着按“上箭头”往回翻看它们。你会注意到不仅能看到最近用过的命令——甚至还能看到上次登录时用过的命令。现在试试 `history` 命令——它会列出你缓存下来的全部命令历史——通常有 100 条甚至更多。围绕它可以做不少巧妙的事情。最简单的就是重复一条命令——挑一行来重复（比如第 20 行），输入 !20 然后按 “Enter” 即可重复它。以后当你输入又长又复杂的命令时，这会*非常*方便。你也可以按 `Ctrl + r`，然后开始输入你要找的命令的任意一部分。你会在提示符处看到一条过去命令的自动补全。如果继续输入，会出现更具体的选项。你可以按回车运行它，也可以先用方向键或其他移动键编辑它。你还可以继续按 `Ctrl + r` 来查看你以不同选项使用过的同一条命令的其他实例。

* 在你主目录里找“隐藏”文件。在 Linux 中，约定很简单：任何以 “.” 字符开头的文件都是隐藏的。所以，输入 `cd` 回到你的“主目录”，然后 `ls -l` 看看那里有哪些文件。现在输入 `ls -la` 或 `ls -ltra`（“a” 表示 “all”）来显示所有文件——包括以点开头的那些。“点文件”最常见的用途就是把个人设置保存在主目录里。所以用你新学的 `less` 技能看看 `.bashrc`、`.bash_history` 以及其他文件的内容。

* 最后，用 `nano` 编辑器在你主目录里创建一个文件，写一篇关于过去五天对你来说进展如何的总结。

## 扩展

我们目前用 `bash` 作为终端 shell（它在许多发行版中都是标准配置），但它并不是唯一的选择。如果你想试试 [zsh](https://www.geeksforgeeks.org/how-to-install-z-shellzsh-on-linux/)、[fish](https://fishshell.com/) 或 [oh-my-zsh](https://ohmyz.sh/)，你会看到有一些差异，而各自的功能通常是主要的区别所在。试试看，随便摸索一下。

之后，你可以再上一个台阶，用**终端复用器（terminal multiplexer）**在同一个终端窗口里同时打开多个 shell 会话。试试 [screen](https://linuxize.com/post/how-to-use-linux-screen/)——它稍微简单一些，也许一开始显得过于简略——或者 [tmux](https://github.com/tmux/tmux/wiki)，它功能多、色彩丰富。网上关于“如何定制你的 tmux”的材料太多了，玩得开心。
