## 简介

Linux 和 Unix 世界之外的多数计算机用户如今不会在命令行上花太多时间，但作为 Linux 系统管理员，这是你的默认工作环境——所以你必须在其中游刃有余。

当你使用 Windows 或 Apple 的 macOS（甚至最新的 Linux 发行版）这样的图形桌面时，你会越来越多地只看到一些简单的“位置”，你的东西就存放在那里——“图片”、“音乐”等等。但只要你稍微懂点技术，就会意识到这一切之下是一个由“文件夹”构成的层级式“目录结构”（例如 Windows 上的 *C:\\Users\\Steve\\Desktop*，macOS 上的 */Users/Steve/Desktop*——而在桌面版 Linux 系统上则是 */home/steve/Desktop*）。

从现在开始，课程会为你指出某个主题的一系列优质在线资源，然后给你一组简单的任务去完成。你完全可以去 Google 其他在线资源、参考你手头的任何书等等——事实上，这门课程设计中的一个基本要素就是**迫使你自己做一点研究**。即使是最有经验的系统管理员也会上网搜索如何使用命令的建议——所以你越早养成这个习惯越好！

## RTFM（去读手册）

这时候正好可以提一句：Linux 众多优势之一就是它被设计成让你了解这个系统、让你学会如何使用它。以文本手册、指南和论坛形式提供的文档，将是你在这段旅程中花时间最多的地方。

专有系统虽然也有一些免费文档，但你更常看到的是使用付费客户支持来解决问题，或者弄清楚某个具体任务该怎么执行。虽然你在 Linux 上也可以这么做（Canonical、RedHat 和 SuSE 就是提供同类支持的公司），但多半不是这种情况。而你是来这里学习的，所以……

这就引出了著名的缩写 [RTFM](https://en.wikipedia.org/wiki/RTFM)。读手册是你在学习一个命令时**第一件**该做的事。我们会介绍获取这类信息的许多方式，但如果搜完之后你还需要更多见解，你总可以在论坛和其他社区里[提一个写得好的问题](https://opensource.com/life/16/10/how-ask-technical-questions)。

先从 `man` 命令开始。每个安装的应用都在这本手册里有自己的一页，所以你可以查看 `pwd` 的那一页来了解语法的完整细节，像这样：

```bash
man pwd
```

你也可以试试：

```bash
man cp
man mv
man grep
man ls
man man
```

> **关于 Ubuntu Minimized 的说明——如果你使用的是[本地服务器/虚拟机](00-Local-Server.md)：**
> 由于这是精简/裁剪版的 Ubuntu Server，很遗憾默认不会安装 `man-db`
> 软件包，你也就没有可用的手册页。要想在不把它恢复成完整版的情况下解决这个问题，
> 只需用 `sudo apt install man-db manpages manpages-dev` 安装所需软件包即可。

你会看到，这些手册对于命令的详细语法非常出色，但很多写得极其简洁，而另一些的细节量则多少有些吓人！

这正是 `tldr` 如此强大的原因！你可以用 `snap install tldr` 安装它，或者按照[它们的 wiki](https://github.com/tldr-pages/tldr/wiki/Clients#official-console-clients) 了解更多选项。

```bash
$ tldr pwd
pwd
Print name of current/working directory.More information: https://www.gnu.org/software/coreutils/pwd.

 - Print the current directory:
   pwd

 - Print the current directory, and resolve all symlinks (i.e. show the "physical" path):
   pwd -P
```

如果你知道某个关键字，或者对命令应该做什么有一些描述，可以试试 `apropos` 或 `man -k`，像这样：

```bash
$ apropos "working directory"
git-stash (1)        - Stash the changes in a dirty working directory away
pwd (1)              - print name of current/working directory
pwdx (1)             - report current working directory of a process

$ man -k "working directory"
git-stash (1)        - Stash the changes in a dirty working directory away
pwd (1)              - print name of current/working directory
pwdx (1)             - report current working directory of a process
```

但你很快会发现，并不是每个命令都有可以用 `man` 阅读的手册。那些命令就包含在 shell 本身之中，我们称之为[内建命令（builtin commands）](https://www.gnu.org/software/bash/manual/html_node/Shell-Builtin-Commands.html)。

有一些是重叠的（也就是既有内建命令，又有手册页），但如果 `man` 不起作用，我们就用 `help` 来显示关于它们的信息。

```bash
$ man export
No manual entry for export

$ help export
export: export [-fn] [name[=value] ...] or export -p
    Set export attribute for shell variables.

    Marks each NAME for automatic export to the environment of subsequently
    executed commands.  If VALUE is supplied, assign VALUE before exporting.

    Options:
      -f        refer to shell functions
      -n        remove the export property from each NAME
      -p        display a list of all exported variables and functions

    An argument of `--' disables further option processing.

    Exit Status:
    Returns success unless an invalid option is given or NAME is invalid.
```

要知道一个命令是否是内建命令，最好的方法就是检查它的 `type`：

```bash
$ type export
export is a shell builtin
```

最后，`info` 会读取以 [info](https://en.wikipedia.org/wiki/Info_(Unix)) 格式存储的文档。

## 在文件结构中导航

* 先读手册：`man hier`
* `/` 是文件夹（也叫目录）分支树的“根”
* 任何时候你都“处在”系统的某个部分——命令 `pwd`（“print working directory”，打印工作目录）会告诉你你在哪里
* 通常你的提示符也被配置为至少给出其中一部分信息，所以如果我“在” _/etc_ 目录里，提示符可能是 `steve@202.203.203.22:/etc$` 或者干脆就是 `/etc: $`
* `cd` 会移动到不同区域——所以 `cd /var/log` 会带你进入 `/var/log` 文件夹——执行它，然后用 `pwd` 检查——再看看你的提示符是否变成了反映你所在位置的样子。
* 你可以通过输入 `cd ..`（“cee dee dot dot”）向结构的“上层”移动——先 `cd` 到 `/var/log/`，然后 `cd ..`，再 `cd ..` 一次，仔细留意你的提示符，或者每次都输入 pwd，来弄清楚你当前的工作目录。
* “相对”位置是基于你当前工作目录的——例如，如果你先 `cd /var`，那么 pwd 会确认你“在” `/var` 中，而你可以用两种方式移动到 `/var/log`——要么用 `cd /var/log` 提供完整路径，要么用命令 `cd log` 提供简单的“相对”路径
* 单单一个 `cd` 总是会让你回到你自己定义的“主目录”，也叫 `~`（“波浪号”字符）[注意：这与 DOS/Windows 不同]
* 一个文件夹里有哪些文件？`ls`（list，列表）命令会给你一份文件及子文件夹的清单。像许多 Linux 命令一样，它有一些选项（称为“开关/switch”）来改变命令的含义或输出格式。先试试简单的 `ls`，然后 `ls -l -t`，再试试 `ls -l -t -r -a`
* 按惯例，以 “.” 开头的文件被视为隐藏文件，`ls` 以及许多其他命令都会忽略它们。`-a` 开关会把它们包含进来。你应该会在自己的主目录里看到一些隐藏文件。
* 关于开关的一点说明：一般来说大多数 Linux 命令都接受一个或多个“参数”和一个或多个“开关”。所以当我们说 `ls -l /var/log` 时，“`-l`”是一个表示“长格式”的开关，而“`/var/log`”是“参数”。许多命令接受大量开关，而且这些开关通常可以合并（所以从现在起，用 `ls -ltra`，而不是 `ls -l -t -r -a`）
* 在你的主目录中输入 `ls -ltra`，看看最左边那一列——那些该行第一个字符为 “d” 的条目是目录（文件夹）而不是文件。它们也可能以不同的颜色或字体显示——如果没有，那么加上 “--color=auto” 开关就能做到（也就是 `ls -ltra --color=auto`）

## 基础目录操作

* 你可以用 `mkdir` 命令新建文件夹/目录，所以先移动到你的主目录，输入 `pwd` 确认你确实在正确的位置，然后创建一个目录，例如创建一个叫 “test” 的目录，只需输入 `mkdir test`。现在用 `ls` 命令看看结果。
* 你还可以创建更多目录，把目录嵌套在目录里，然后用 `cd` 命令在它们之间导航。
* 当你想把那个目录移动到另一个目录里时，就用 `mv` 并指定要移动到的路径。
* 要删除（或移除）一个目录，如果目录是空的就用 `rmdir`，如果里面还有文件或其他目录就用 `rm -r`。

## 基础文件操作

* 你可以用 `touch` 命令新建空文件，这样你就能再多探索一下 `ls` 命令。
* 当你想把那个文件移动到另一个目录时，就用 `mv` 并指定要移动到的路径。
* 要删除（或移除）一个文件，用 `rm`。

## 小结

能够在命令行上自信地在目录结构之间移动很重要，所以别以为你可以跳过它！不过，这些技能会在课程的二十天里被你不断使用，所以如果它没能立刻“开窍”，也不要灰心。

## 扩展

如果这些对你来说已经很熟悉了，那么：

* 学习 `pushd` 和 `popd`，轻松在多个目录之间导航。运行 `pushd /var/log` 会把你移动到 `/var/log`，但会记录你原来的位置。你可以一次 `pushd` 多个目录。试试看：`pushd /var/log`、`pushd /dev`、`pushd /etc`、`pushd`、`popd`、`popd`。注意不带参数的 `pushd` 会在最近 _push_ 的两个目录之间切换，但[更复杂的导航也是可能的](https://opensource.com/article/19/8/navigating-bash-shell-pushd-popd)。最后，`cd -` 也会把你移动到上一次访问的目录。
