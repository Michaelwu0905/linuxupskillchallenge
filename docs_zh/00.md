## 要求

首先，你需要一台服务器。没有自己的服务器，你就无法学习如何管理一台远程 Linux 服务器——所以今天我们就去搞一台。

借助 Linux 与虚拟化的魔力，现在几乎可以即时地搭建起一台小型的互联网服务器——而且成本非常低。从技术上讲，你要做的是创建并租用一台 VPS（虚拟专用服务器）。在某个数据中心里，一台运行 Linux 的物理服务器会使用 KVM（基于内核的虚拟机）功能被切分成十几台甚至更多虚拟机，这个功能从 2007 年初就已成为 Linux 的一部分。你只是租用其中一小部分硬件算力来运行你自己的那台小服务器。

总而言之，**你将在某处的物理计算机内部创建一台虚拟机（VM）**。那个“某处”[理想情况下会是云服务商的数据中心](how-this-works.md)内，但你也可以自由使用自己的个人电脑或其他可用的硬件，只要它具备网络连接以便：

* 进行软件更新和安装
* 可以通过 SSH 被远程访问

无论你的虚拟机运行在哪里，本课程涵盖的大多数命令的运行方式都完全相同。

除了托管服务商之外，我们还需要选择要在服务器上安装哪种 Linux“口味”。如果你是 Linux 新手，可用的各种“发行版”可能会让你困惑——不过 Ubuntu Server 最新的 LTS（长期支持）版本是一个流行的选择，[这也是本课程要使用的版本](how-this-works.md)。

## 但是……你有没有我可以直接用的免费服务器？

我们刚刚在 [Killercoda](https://killercoda.com/linux-upskill-challenge) 上启动了**测试版基础场景**，你可以原样运行所有课程（第 12 天除外）。单节课的场景仍在开发中，但现在你有了一台基本就绪的 Ubuntu 服务器，无需操心搭建虚拟机和 SSH 密钥。

[SadServers](https://sadservers.com) 也有一个[测试版场景](https://sadservers.com/scenario/luc)，运行一台空白 Debian 11 服务器，但有一些限制。如果你对 Linux 已有些了解，并且更愿意在现成场景中操作，而不是自己搭建服务器，SadServers 是练习故障排查技能的好地方。

## 那么，我该如何选择？

**[本地服务器或本地虚拟机](00-Local-Server.md)：** 如果与云服务商打交道完全不可行，这是一个合理的选择。WSL 让很多人第一次轻松接触到 Linux，VirtualBox 作为虚拟化软件也久经考验。不管怎样，这都是进入 Linux 世界的老牌方法。*至少你不会被要求装双系统。*

**[云上（使用 DigitalOcean、Linode 和 Vultr 之类的服务商）](00-VPS-small.md)：** 比大厂更精简、更少官僚手续，你对服务器有相当大的控制权，并且在服务器应该如何运作上要自己做更多决定。这是许多完成 Linux Upskill Challenge 的人的首选。

**[云上（使用 AWS、Azure 和 Google Cloud 之类的服务商）](00-VPS-big.md)：** 看看大厂对你来说是否划算，尤其是如果你是学生。教育套餐和期限最长的免费套餐都属于这一类。这里也是大多数[“云账单恐怖故事”](https://www.reddit.com/r/aws/comments/1k1lkkp/cloud_billing_horror_stories/)发生的地方。不过人们忘了告诉你，那些把账单炸掉的产品和配置是什么；*剧透一下：并不是一台最小的服务器*。

看看你的选项，找出最适合你的。花点时间看看[配套视频](https://youtube.com/live/_-6UYOjRIVQ)，你的大部分问题都能在那里得到解答。
