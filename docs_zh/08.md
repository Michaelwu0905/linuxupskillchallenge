# Day 8 - 大名鼎鼎的 “grep” 与其他文本处理器

* [课程视频](https://youtu.be/kG5JGJN5iTc)
* 配套视频：[文本处理和其他有用的命令行工具](https://www.youtube.com/live/WtcX60n-ui0?t=2517s)

## 简介

你的服务器现在运行着两个服务：你用来登录的 *sshd*（Secure Shell Daemon）服务，以及 Apache2 Web 服务器。当你和其他人访问你的服务器时，这两个服务都在生成日志——而这些是文本文件，我们可以用一些简单的工具来分析它们。

纯文本文件是“Unix 之道”的关键部分，也有许多小巧的“工具”让你能轻松地编辑、排序、搜索以及用其他方式操作它们。今天我们会用 `grep`、`cat`、`more`、`less`、`cut`、`awk` 和 `tail` 来把日志切块、切片。

`grep` 命令之所以有名，是因为它极其强大好用，也因为它那个“书呆子气”的名字正是 Unix/Linux 命名传统的典型代表。

## 今天的任务

* 用 `cat` 把文件的完整内容倒出来，像这样：`cat /var/log/apache2/access.log`
* 用 `less` 打开同一个文件，像这样：`less /var/log/apache2/access.log`——用方向键在文件中上下移动，然后用 “q” 退出。
* 再次用 `less` 查看一个文件，但要有信心地练习用 *gg*、*GG* 和 */*、*n* 和 *N* 四处移动（分别用于跳到文件顶部、文件底部、搜索某个内容，以及跳到下一个“命中”或回到上一个）
* 用 `less` 查看 `/var/log/auth.log`，了解最近的登录和 `sudo` 使用情况
* 用 `tail /var/log/apache2/access.log` 只看文件的末尾部分（是的，还有一个 `head` 命令！）
* 用 `tail -f /var/log/apache2/access.log` 实时跟踪日志（同时在浏览器中访问你服务器的网页）
* 你可以把一条命令的输出用 `|`（管道）符号“管道”成另一条命令的输入
* 所以，用 `cat` 倒出一个文件，但把输出用管道送给带搜索词的 `grep`——像这样：`cat /var/log/auth.log  | grep "authenticating"`
* 把它简化成：`grep "authenticating" /var/log/auth.log`
* 管道让你能收窄搜索范围，例如 `grep "authenticating" /var/log/auth.log | grep "root"`
* 用 `cut` 命令，通过指定 “-d”（分隔符）和 “-f”（字段）来选出每行中最有意义的部分——像这样：`grep "authenticating" /var/log/auth.log| grep "root"| cut -f 10- -d" "`（第 10 个字段起，字段之间的分隔符是 “ ” 字符）。这种方法在从日志数据中提取有用信息时非常实用。
* 用 `-v` 选项反转选择，找出用其他用户登录的尝试：`grep "authenticating" /var/log/auth.log| grep -v "root"| cut -f 10- -d" "`

任何命令的输出都可以用 “>” 操作符“重定向”到文件。命令 `ls -ltr > listing.txt` 不会把目录内容列到你的屏幕上，而是重定向进文件 “listing.txt”（如果该文件不存在就创建它，如果存在就覆盖其内容）。

## 我的 /VAR/LOG/AUTH.LOG 在哪儿？

如果你没找到 `/var/log/auth.log` 这个文件，那你大概用的是精简版 Ubuntu（可能是你自己的本地虚拟机，也可能是某个 VPS 上的版本）。那个精简镜像是，嗯……很精简。它只有 systemd journal 可用，默认没有带上旧的 syslog 系统。

但别担心！要把它找回来，`sudo apt install rsyslog`，文件就会被创建出来。给它几分钟填充内容，然后再做这一课。

它也可能缺少我们在挑战中用到的其他一些程序，但你可以随时安装它们。

## 扩展

* 看看你能否把你对 `auth.log` 的过滤进一步扩展，只选出 IP 地址，然后把管道接到 `sort`，再接到 `uniq`，得到一份替你“审计”服务器安全的全部 IP 地址清单。
* 研究 `awk` 和 `sed` 命令。当你用 `grep` 和 `cut` 难以弄清某件事该怎么做时，你可能就需要升级到用它们。在 Google 上搜 “linux sed tricks” 或 “awk one liners” 会给你很多例子。
* 目标是至少学会 `awk` 和 `sed` 各自一个简单有用的小技巧。
