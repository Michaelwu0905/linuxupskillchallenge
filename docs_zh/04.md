## 简介

作为系统管理员，你的关键任务之一就是按需安装新软件。同时你还需要非常熟悉 Linux 系统中标准目录的布局。

在今天的课程中，这两方面你都会得到练习。

## 今天的任务

* 从在线软件仓库安装一个新应用
* 熟悉一些标准目录
* 查看一些配置文件的格式和内容

如果你用过智能手机的“应用商店”或“市场”，那么你会立刻理解从标准仓库安装 Linux 软件的常规方式。只要我们知道某个软件包（=应用）的名称或描述，就可以搜索它：

     apt search "midnight commander"

这会显示一系列匹配的“软件包”，然后我们可以用 `apt install` 命令安装它们。所以在 Ubuntu 上安装软件包 `mc`（Midnight Commander）：


     sudo apt install mc


（除非你已经以 `root` 用户登录，否则需要在安装命令前加上 `sudo`——因为普通用户不允许安装可能影响整台服务器的软件。）

现在你已经装好了 `mc`，只需输入 `mc` 并按 *Enter* 就能启动它。

这不是一个“经典”的 Unix 应用，但一旦你接受了它复古的界面，就会发现导航相当容易，所以去找找这些目录：

`/root`
`/home`
`/sbin`
`/etc`
`/var/log`

……并使用下面“资源”部分中的链接来开始理解它们的用途。你也可以通过输入 `man hier` 来阅读关于这套层级结构的官方手册。

大多数关键配置文件都放在 `/etc` 及其子目录下。这些文件，以及 `/var/log` 下的日志，几乎无一例外都是纯文本文件。接下来几天你会花很多时间和它们打交道——但现在只需用 F3 查看它们的内容。

一些值得看的文件：`/etc/passwd`、`/etc/ssh/sshd_config` 和 `/var/log/auth.log`

再次用 F3 退出文件查看界面。

F10 会退出 `mc`，不过你可能需要用鼠标来选择它。

（在 Apple Mac 的终端里，你可能需要用 ESC+3 来代替 F3，用 ESC+0 代替 F10）

现在用 `apt search` 搜索并安装更多软件包：试着搜索 “hangman”。你大概会发现一个老式的基于文本的版本包含在名为 `bsdgames` 的软件包里。安装它，玩上几轮……

## 扩展

* 用 `mc` 查看 `/etc/apt/sources.list.d/ubuntu.sources`，那里指定了软件仓库的实际位置。通常这些会是“镜像”站点，比 Ubuntu 主服务器离你的服务器更近。
* 阅读 [Repositories - CommandLine](https://help.ubuntu.com/community/Repositories/CommandLine) 了解更多细节。
