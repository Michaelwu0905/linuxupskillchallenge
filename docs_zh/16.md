# Day 16 - 归档与压缩

## 简介

作为系统管理员，你需要能够自信地处理压缩的“归档”文件。特别是你的两项关键职责——安装新软件和管理备份——经常需要它。

在其他操作系统上，WinZip 以及更早的 `pkzip` 之类的应用长期以来被用来把一系列文件和文件夹收进一个扩展名为 `.zip` 的压缩文件中。

然而，归档和压缩实际上是两个不同的过程，只是经常被一起使用。归档把多个文件合并成一个“箱子”，同时保留它们的结构和属性，但不会改变数据总大小。压缩则使用复杂的算法高效地编码数据，通过缩小那个文件来节省存储空间。

## 压缩文件

压缩的目标是减小文件大小。更小的文件占用更少带宽，也能更快地通过网络传输。不同的工具用不同的算法来实际缩小那些数据。

你可以像这样用 GZip 压缩一个文件：

`gzip my-big-file`

……这会创建 `my-big-file.gz`，但会替换掉原文件。如果你想保留未压缩的文件，试试：

`gzip -vk my-big-file`

这里用 `-v` 让命令“详细（verbose）”，用 `-k` 保留原文件。

到了解压的时候，用 `-d` 开关，像这样：

`gzip -d my-big-file.gz`

常用工具：

* [gzip](https://www.gnu.org/software/gzip/manual/gzip.html)：非常常见而且快。
* [bzip2](https://manned.org/bzip2)：更慢，但通常能生成更小的文件。
* [xz](https://manned.org/xz)：目前 Linux 中空间效率最高的工具。

无论用哪个工具，文本通常都能压缩得很好。JPEG/MP4 文件可能压缩不了多少，因为这些格式本身已经有一定程度的压缩了。

## 创建归档

那么，你可以像这样为你 _/etc/init.d_ 文件夹中的当前文件创建一个“快照”：

`tar -cvf myinits.tar /etc/init.d/`

这会在你当前目录中创建 _myinits.tar_。

**注意 1：** `-f` 开关指定了_“输出应该写到紧随其后的那个文件名”_——所以在这种情况下开关的顺序很重要。**非常重要**：`tar` 会把 `-f` 之后的任何内容当作需要创建的归档文件名。所以，创建归档时我们应该始终把 `-f` 作为最后一个标志。

**注意 2：** 加入 `-v` 开关（verbose）是为了给出一些反馈——传统上许多工具除非失败，否则不提供任何反馈。

（“tar” 这个神秘的名字？——最初是 “tape archive”（磁带归档）的缩写）

然后你可以像这样用 GnuZip 压缩这个文件：

`gzip myinits.tar`

……这会创建 `myinits.tar.gz`。像这样的压缩 tar 归档被称为 “tarball”。你有时也会看到扩展名为 _.tgz_ 的 tarball——在 Linux 命令行上这对系统没有任何含义，只是对人类有帮助而已。

在实践中，你可以用 `-z` 开关一步完成这两步，像这样：

`tar -cvzf myinits.tgz /etc/init.d/`

这里用 `-c` 开关表示我们在创建一个归档；`-v` 让命令“详细”；`-z` 压缩结果——而 `-f` 指定输出文件。

## 提取归档

要“炸开”一个归档并取回你的文件，用 `-x`（extract，提取）标志：

`tar -xvf archive.tar.gz`

**安全第一：** 提取之前，用 `-t`（list，列出）标志预览内容是个好习惯：

`tar -tf archive.tar.gz`

这能让你对提取后文件结构会变成什么样有个概念。如果列表里显示许多没有共同前缀（比如 folder/file）的文件，那你就遇到了一个 _tarbomb_。不，不是[这个](https://xkcd.com/1168/)。提取它可能会把文件直接倾倒进你当前目录，有可能覆盖已有文件。

你可以用 `-C` 标志把文件提取到指定的目标目录中，保持整洁。

`tar -xvf archive.tar.gz -C target_dir/`

## 扩展

你可能会注意到有些教程写的是 `tar cvf` 而不是带开关字符的 `tar -cvf`——你知道为什么吗？[提示](https://unix.stackexchange.com/questions/28403/tar-cvf-or-tar-cvf)：这与旧的 “tape archive” 风格和现代兼容性有关。

关于**压缩级别**的一点说明——大多数工具允许你用一个数字刻度（1–9）来调整速度与大小之间的平衡：

* 级别 1：快，但压缩率低。
* 级别 6：默认设置；速度和大小的平衡点。
* 级别 9：最佳压缩（文件最小），但耗时最长。

不过，在创建 tarball 时调用压缩工具，`tar` 只会使用默认的级别 6。
