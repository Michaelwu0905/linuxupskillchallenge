## 简介

现在你已经拥有自己的可访问互联网的服务器有一段时间了，也看到了如何在其上创建和编辑小文件。你已经建立了一个 Web 服务器，能够编辑一个简单的网页。

今天我们要看看如何在你的其他系统和这台服务器之间移动文件——比如这些任务：

* 从服务器上取一些文件到你的桌面机器上
* 把一些文本复制到服务器上，放到你的网页里
* 为你的网页上传一些照片和 logo

## 今天的任务

* 上传一个文件到服务器

* 同步一份备份

## 协议

Linux 服务器共享文件的方式有很多，包括：

* SMB：微软的文件共享，在 Windows 机器组成的局域网中很有用
* AFP：Apple 的文件共享，在 Apple 机器组成的局域网中很有用
* WebDAV：通过 Web（http）协议共享
* FTP：传统的互联网共享协议
* scp：简单支持文件复制
* rsync：快速、非常高效的文件复制
* SFTP：通过 SSH 协议进行文件访问和复制（尽管名字相似，但技术层面 SFTP 协议与传统 FTP 完全无关）

这些各有各的用武之地，但对于在你的本地桌面和服务器之间来回复制文件来说，SFTP 有一些关键优势：

* 你的服务器不需要任何额外配置
* 顶级的安全性
* 允许浏览目录结构
* 你可以创建和删除文件夹

如果你能成功地从家里、公司或网吧通过 _ssh_ 登录，那么你也能从同一个地方使用 SFTP，因为底层用的是同一个协议。

相比之下，为其他任何协议配置服务器都需要额外的工作。不仅如此，启用额外协议还会增大“攻击面”——而且总有可能会因为配置不当而让攻击者进来。此外，工作场所的限制性防火墙策略也很可能会干扰或阻断这些协议。最后，虽然老式 FTP 仍然非常常用，但它以“明文”发送登录凭据，所以你的室友、咖啡馆伙伴或雇主都可能通过网络“抓包”拿到它们。对你这台“课堂”服务器来说不是什么大问题——但如果你在远程管理生产服务器，这就是不可接受的风险。

## SFTP 客户端软件

使用 SFTP 需要一些客户端软件。每个 Apple OSX 或 Linux 系统都标配一个命令行客户端（不出所料地叫 _sftp_）。如果你用的是 Linux 桌面，你的文件管理器里也内置了 GUI 客户端。这让你能轻松地通过 SFTP 连接到远程服务器。（例如对于 Nautilus 文件管理器，按 ctrl + L 调出“位置窗口”，然后输入：_sftp://username@myserver-address_）。

虽然 Windows 和 Apple macOS 没有内置的 GUI 客户端，但有大量第三方选项可用，既有免费的也有商业的。如果你还没装这类客户端，就选一个，比如：

* WinSCP 或 FileZilla——给 Windows 用户
* CyberDuck 或 FileZilla——给 macOS 用户

下载地址在“资源”部分。

配置和使用你选的那个应该很直接。唯一可能让人困惑的地方是：这些客户端通常支持各种协议，比如 scp 和 FTP，而我们不会用它们。当它问你 SERVER（服务器）时，给服务器的 IP 地址；PORT（端口）会是 22；PROTOCOL（协议）会是 SFTP 或 SSH。

## 说明

* 配置你选好的 SFTP 客户端，以你的用户名登录服务器
* 从服务器复制一些文件到你的本地桌面（试试你“home”文件夹里的文件，以及 `/var/log` 里的文件）
* 在服务器上你的 “home” 文件夹下创建一个 “`images`” 文件夹，然后从你的桌面机器上传一些图片进去
* 上到根目录。你应该会看到 `/etc`、`/bin` 和其他文件夹。试着在这里也创建一个 “`images`” 文件夹——这应该会失败，因为你是以普通用户登录的，所以你没有权限创建新文件或文件夹。在你自己的 “home” 目录里，你当然拥有完全权限。

文件上传完之后，你可以通过 _ssh_ 登录，并使用 `sudo` 给自己必要的权限来移动文件。
